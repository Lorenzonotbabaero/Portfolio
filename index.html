About me

Hi! I'm Lorenzo II C. Badilla, a Grade 12 student currently taking Computer Systems Servicing. I'm also a beginner web developer who enjoys creating simple and creative websites. I'm learning HTML, CSS, and JavaScript to improve my coding skills and build better projects. My goal is to keep learning, exploring new ideas, and growing as a developer.

In Computer Systems Servicing, I learn how to assemble, install, and maintain computer systems. I practice installing operating systems and software and setting up computers so they run properly. I also learn how to set up basic computer networks and connect devices together. Troubleshooting is a big part of the course, where I find and fix both hardware and software problems. These skills help me understand how computers work and prepare me for a future career in IT.
